# 🏰 Disney Web Platform

A full-stack Disney-inspired web platform that combines movie discovery, ticket booking, e-commerce, and management features in one application.

## ✨ Features

### 🎬 Movie Discovery
- Browse a collection of Disney movies
- View movie posters and basic information
- Select a movie to view its details
- View movie descriptions and introductions
- Explore movie-related content

> Note: The movie section currently provides movie information and discovery only. Video streaming is not implemented.

### 🎟️ Ticket Booking
- Browse available attractions and ticket options
- View ticket information
- Select ticket options
- Submit ticket reservations
- View and manage booking information

### 🛍️ E-Commerce
- Browse available products
- View product details
- Add products to the shopping cart
- Update product quantities
- Manage shopping cart
- Complete the checkout process
- View order information

### 👤 User
- User registration
- User login
- Manage personal information
- Browse movies and products
- Book tickets
- Manage shopping cart
- View booking and order information

### 🛠️ Admin
- Manage products
- Manage users
- Manage tickets
- Manage bookings
- Manage orders
- Update application content and data

### 💬 Chatbot
- Integrated chatbot for user interaction
- Assist users while exploring the platform
- Provide a more interactive user experience

## 🛠️ Tech Stack

**Frontend:** ReactJS, JavaScript, HTML, CSS  
**Backend:** Node.js, Express.js, RESTful API  
**Database:** SQL  
**Tools:** Git, GitHub, npm
